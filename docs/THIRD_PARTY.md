|---|---|
| **Identifier** | `Qwen/Qwen2.5-1.5B-Instruct` |
| **Publisher** | Qwen Team, Alibaba Cloud |
| **URL** | <https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct> |
| **Licence** | Apache-2.0, as stated on the model card |
| **Architecture** | `Qwen2ForCausalLM`; 28 hidden layers, hidden size 1536, 12 attention heads, 2 key-value heads (grouped-query attention), vocabulary 151,936, `torch_dtype: bfloat16` — verified against the published `config.json` |
| **Parameters** | 1.54 B total, 1.31 B non-embedding |
| **Revision used** | Not recorded. The experiment scripts call `AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-1.5B-Instruct")` with no `revision=` argument, so each run resolved to whatever the repository's default branch pointed at on that date. Pin a revision on future runs. |

The scripts load the checkpoint in `float16` for the frozen base model
(`dtype=torch.float16`) while adapter parameters stay `float32`; the published
checkpoint is `bfloat16`.

## Dataset

The experiments do not read a public dataset directly. They read 50 clinical
scenario fact blocks defined in DiaLense, whose clinical content is grounded in
MTS-Dialog. Both links in that chain are documented in
[`../data/README.md`](../data/README.md); the licence terms are here.

### What this repository ships

Nothing from either source is committed here. `data/scenarios.jsonl` is
generated by `tools/fetch_scenarios.py` and is gitignored. Result files under
`results/` contain measured numbers and, in `_meta`/`_note` fields, short
descriptions of the design — no scenario text and no corpus text.

If you redistribute anything derived from the scenarios, the CC BY 4.0
attribution above travels with it. See [`../LICENSE-DATA`](../LICENSE-DATA).

**On the adapter's licence.** The adapter is a derivative of an Apache-2.0
model, and Apache-2.0 permits derivative works provided the licence and notices
are retained. Releasing the adapter under Apache-2.0 keeps that chain
unambiguous. Two obligations travel with it and are carried in the model card:
attribution to the Qwen Team for the base model, and the CC BY 4.0 attribution
to Ben Abacha et al. for the MTS-Dialog-derived training data. The adapter
weights are useless without the base model, which the user obtains under the
Qwen Team's own terms; nothing here relicenses it.
